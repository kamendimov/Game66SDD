# Game66 — Out of Scope

This document lists features and work items that are intentionally out of scope for the current implementation phase.

- Full scoring validation for 20 / 40 sets
- Game-over detection and winner announcement
- Sound effects, animations, or advanced UI polish
- Advanced AI difficulty levels
- Multiplayer / networked play
- Settings persistence (volume, themes, etc.)
- Accessibility improvements beyond basic UI controls
- Localization / multi-language support
